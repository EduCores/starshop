Cómo funciona:

Webpay: Checkout → POST /api/webpay (buyOrder, amount, returnUrl=http://TU_DOMINIO/checkout/webpay/return) → devuelve {url, token} → window.location = url?token_ws=token → usuario paga en Transbank → vuelve a /checkout/webpay/return?token_ws=... → POST /api/webpay/commit → si status=AUTHORIZED y response_code=0 → éxito.
MercadoPago: Checkout → POST /api/mercadopago (items, payer, back_urls) → devuelve init_point → redirige → vuelve a /checkout/success?gateway=mercadopago.
Transferencia: sin API, guarda orden y muestra en /checkout/success los datos Banco de Chile 123-45678-90 / 76.123.456-7.
